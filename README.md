# AI-Driven Jira/Linear Assistant 🚀

**AI-Driven Jira/Linear Assistant** — это инструмент автоматизации работы Technical Project Manager / Product Owner. Микросервис анализирует сырые бизнес-требования (PRD, BRD, заметки со встреч), декомпозирует их на атомарные User Stories по методологии Agile/Scrum и генерирует структурированный бэклог, готовый к импорту в таск-трекеры.

Проект разработан для демонстрации архитектурных навыков на стыке управления продуктом и разработки AI/ML решений.

---

## 🛠 Технологический стек

* **Frontend:** Vue 3, TypeScript, Vite, Tailwind CSS (v4), Lucide Icons.
* **Backend:** Python 3.11, FastAPI (Asynchronous API), Pydantic v2 (для Structured Outputs), Uvicorn.
* **AI Интеграция:** OpenAI API / Anthropic API (с гибким переключением моделей через переменные окружения).
* **DevOps/Infrastructure:** Docker, Docker Compose (мультиэтапные сборки для оптимизации продакшн-образов).

---

## 🏗 Архитектурные особенности проекта

1. **Structured Outputs (Гарантия схемы):** Использование новейших методов валидации Pydantic гарантирует, что ответ от LLM строго соответствует JSON-схеме приложения. Фронтенд застрахован от "битых" данных.
2. **Fallback Mock-Mode (Демо-режим):** Проект снабжен интеллектуальным демо-режимом. Если API-ключ OpenAI не задан, бэкенд бесшовно переключается на генерацию локальных мок-данных высокого качества на русском языке. Это позволяет запустить и протестировать продукт без затрат на токены.
3. **Containerization Ready:** Проект полностью готов к развертыванию в облачной инфраструктуре (AWS/Yandex Cloud) благодаря микросервисной контейнеризации через Docker Compose.

## 🚀 Как запустить проект локально

### 🔑 Настройка переменных окружения (.env)

Перед запуском проекта (как через Docker, так и локально) необходимо настроить конфигурационный файл для бэкенда:

1. Перейдите в папку `backend/`.
2. Скопируйте файл `.env.example` и переименуйте его в `.env`:
   ```bash
   cp .env.example .env
   ```
3. Откройте созданный файл `.env` и укажите ваш действующий ключ OpenAI API:
   ```text
   OPENAI_API_KEY=sk-proj-...Ваш_Реальный_Ключ...
   OPENAI_MODEL=gpt-4o-mini
   PORT=8000
   ```

> 💡 **Примечание:** Если у вас нет активного ключа OpenAI API, вы можете оставить дефолтное значение-плейсхолдер. Бэкенд автоматически распознает его и переключит приложение в безопасный **Fallback Mock-Mode**, отдавая структурированные тест-кейсы на русском языке без отправки сетевых запросов к OpenAI.


### Вариант 1: Через Docker (Рекомендуемый)

Убедитесь, что у вас установлен Docker и Docker Compose. Выполните команду в корневой папке проекта:

```bash
docker-compose up --build
```
После сборки приложение будет доступно по адресу: `http://localhost` (Фронтенд) и `http://localhost:8000/docs` (Интерактивная документация Swagger).

### Вариант 2: Локальный запуск для разработки

**1. Бэкенд (FastAPI):**
```bash
cd backend
python -m venv venv
# Активируйте окружение (для Windows: .\venv\Scripts\activate)
pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

**2. Фронтенд (Vue 3):**
```bash
cd frontend
npm install
npm run dev
```
